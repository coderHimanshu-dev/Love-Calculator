# 💖 Love Calculator

A fun and interactive **Love Calculator Web App** built using **HTML, CSS, and JavaScript**.  
This project calculates a random love compatibility percentage between two people and displays a sweet result with a modern romantic UI.

🌐 **Live Demo:** https://love-calculator-him.netlify.app/

---


## ✨ Features

- 💘 Calculate love percentage instantly
- 🎨 Beautiful romantic UI design
- ⚡ Fast and responsive performance
- 📱 Fully mobile responsive
- ❤️ Interactive animations and effects
- 😄 Fun compatibility messages

---

## 🛠️ Built With

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**
